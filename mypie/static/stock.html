🔑토스증권 연결하기

  1. PC에서 토스증권 웹(WTS)에 로그인 → 설정 → Open API에서 Client ID · Client Secret을 발급받아요.
  2. 같은 화면 허용 IP 관리에 집 IP - 를 등록해요.
  3. 토스증권 앱에서 투자자지시 거래소를 통합(SOR)으로 해 두세요. 아니면 주문이 거절돼요.
  4. 파이에서 python3 -m mypie.toss 를 실행하고 두 값을 붙여넣으면 끝이에요. 1분 안에 이 화면이 살아나요.

키는 파이의 .env 파일에만 저장되고, 처음에는 모의투자(가상 돈 100만 원)로 시작해요.
