# My_Pie 🥧

라즈베리파이 3B에서 24시간 돌아가는 **업비트 코인 자동매매 봇**, **토스증권 국내 주식 자동매매 봇**과 **모니터링 웹페이지**예요.

- **포트폴리오**: "비트코인은 일봉 이동평균 50% + 이더리움은 1시간봉 터틀 30%"처럼 **종목 + 판단 주기 + 전략 + 비중(%)** 줄을 최대 10개까지 만들고, 줄마다 따로 사고팔아요. 비중 0%는 '지켜보기만' 하는 줄이에요
- 유명한 매매 전략 **13가지**(해외 TradingView 인기 1·2위 지표 포함)를 종목별로 업비트 과거 데이터로 매일 **백테스트해서 순위**를 매겨요
- **살 때·팔 때 조합**: 살 때와 팔 때 전략을 따로 고르고, 한쪽에 두 전략을 "그리고/또는"으로 묶을 수 있어요 ([조합과 손절선](#살-때팔-때-조합과-손절선))
- **손절선**(선택): 산 값보다 정한 %만큼 떨어지면 전략과 상관없이 팔아요
- **전략 시뮬레이션**: 종목·주기·전략(조합)·손절선·과거 기간을 골라 "그때 이렇게 사고팔았다면?"을 차트와 순위로 보여줘요
- 웹페이지에서 **포트폴리오 · 계좌(모의투자/실거래) · 투자 한도(금액 또는 계좌 전액)**를 바꿔요 (PIN 보호)
- **모의투자**로 먼저 검증하고, 준비되면 **실거래**로 바꿔요
- 정전·재부팅·통신 끊김이 있어도 **멈추지 않고** 업비트에 주문 결과를 확인해서 바로 이어서 매매해요
- **주식(토스증권)**: 계좌 하나를 **금고 + 종목 계좌** 여러 개로 나눠 써요. 종목 계좌마다 종목 하나 + 전략(조합)으로 따로 사고팔아요 ([주식 자동매매](#주식-자동매매-토스증권))
- **텔레그램**: 로그인 코드, 매매·오류 알림, 아침·마감 리포트, 명령어, **API 키 만료 알림(갱신 방법 포함)**, **SSH 로그인 감시**
- 외부 라이브러리 없이 파이에 기본으로 있는 Python 3만 써요 (메모리 약 50MB)

**대시보드**: 총 자산과 실제 비중 도넛, 종목별 카드(목표 비중 대비 실제 비중·오늘 계획·줄 수익률, 괄호 안에 **그냥 들고 있었다면(바이앤홀드)** 수익률·손익), 포트폴리오 편집기,
실시간 가격과 오늘 고가·저가, 다음 판단까지 카운트다운, 매수▲·매도▼가 표시된 캔들 차트(**5년·1년·6개월·3달·1개월·1주·1일·1시간**, 폰에서는 고르는 칸),
성과 통계(승률·연승·최고/최악 매매·수수료), 전략 시뮬레이션과 같은 기간 순위·수익 곡선 비교, 손익 캘린더, 오늘의 급등·급락 코인,
자산 추이, 매매 기록·이벤트, 라즈베리파이 상태(온도·CPU·메모리·저장공간·**추정 전력(W)과 권장 어댑터**·전원 부족 감지), 집 IP 변경 경고, 매매 체결 알림 팝업

> ⚠️ 이 프로그램은 투자 조언이 아니에요. 백테스트 순위는 "과거에 이렇게 했다면?"일 뿐 앞으로의 수익을 보장하지 않아요. 실거래는 잃어도 괜찮은 금액으로만 하세요.

## 동작 방식

1. 포트폴리오는 여러 **줄**로 되어 있고, 줄마다 **종목 + 전략 + 비중(%)**이 있어요. 비중 합계는 100% 이하이고, 남는 %는 **대기 원화**로 둬요.
   - 돈도 줄마다 따로예요. 각 줄은 `전체 자산 × 비중`만큼의 몫을 받고, 그 안에서만 사고팔아요. 한 줄이 다른 줄의 돈을 쓰지 않아요.
2. 줄마다 **판단 주기**를 골라요: **일봉 / 4시간봉 / 1시간봉 / 15분봉**. 그 주기의 새 봉이 시작될 때마다 전략이 직전까지의 봉을 보고 **이번 계획**을 세워요.
   - 일봉은 매일 **09:00(KST)**, 4시간봉은 09·13·17·21·01·05시, 1시간봉은 매시 정각, 15분봉은 15분마다예요.
   - 주기가 짧을수록 매매가 잦아져서 **수수료**가 많이 쌓이고 잡음에 흔들려요. 순위표도 주기마다 따로 계산하니 꼭 비교해 보세요.
   - 예: "오늘 1억 1,105만 원을 넘으면 매수", "매도 신호", "보유 유지", "관망"
   - **매도 신호가 난 줄만** 팔아요 ("보유 유지"는 그대로). 판 돈을 바로 쓸 수 있게 매도를 먼저, 매수를 나중에 처리해요.
   - 봉 시작에 판 줄은 그 봉 시작에 **다시 사지 않아요** (조합에서 사자·팔자가 같이 켜졌을 때 사고팔기만 반복하지 않게).
3. **10초마다** 현재가를 확인하면서 계획대로 사고팔아요 (돌파 매수, 이탈 매도, 손절선).
4. 하루 한 번 포트폴리오 **종목 × 주기**마다 **13개 전략을 백테스트**해서 순위를 다시 매겨요 (일봉은 3년, 4시간봉 1,500봉, 1시간·15분봉 2,000봉). 편집기의 전략 목록이 이 순위대로 나와요.
5. 모든 기록은 `data/mypie.db`(SQLite)에 남고, 웹페이지(`http://<파이 IP>:8000`)가 그걸 5초마다 보여줘요.
6. 종목 카드의 수익률·손익 아래 괄호에는 **같은 돈을 같은 때 넣고 그냥 들고 있었다면** 얼마였을지가 같이 나와요. 전략이 "그냥 들고 있기"보다 나은지 바로 볼 수 있어요.

웹페이지에서 포트폴리오를 바꿀 때는:
- **빠진 줄**이나 **종목·전략(조합)·판단 주기가 바뀐 줄**은 보유 중이면 먼저 팔아요. 저장 전 확인 창에 "바로 매도돼요"로 알려줘요.
- **비중만 바뀐 줄**은 팔지 않고 몫만 다시 나눠요 (늘어난 몫은 추가 매수).
- **손절선만 바꾼 줄**도 팔지 않아요. 다만 새 손절선이 지금 가격보다 위면 곧바로 손절돼요 (확인 창에 알려줘요).
- **계좌**(모의↔실거래, 한도)가 바뀌면 전부 팔고 새 계좌로 시작해요.

## 전략 13가지 설명

| 전략 | 사는 때 | 파는 때 | 잘 맞는 장 |
|---|---|---|---|
| **변동성 돌파** | 가격이 `오늘 시가 + 어제 변동폭 × 0.5`를 넘을 때 | 다음 날 09시 | 하루 단위 급등 |
| **변동성 돌파 + 이동평균** | 위와 같되, 어제 종가가 5일 평균 위일 때만 | 다음 날 09시 | 상승 추세 |
| **이동평균 골든크로스** | 5일 평균 > 20일 평균 | 5일 평균 < 20일 평균 | 긴 추세 |
| **RSI 역추세** | RSI < 30 (과매도) | RSI > 70 (과매수) | 박스권 |
| **볼린저 밴드** | 종가가 밴드 하단 아래 | 종가가 중심선 위 | 박스권 |
| **MACD** | MACD선 > 시그널선 | MACD선 < 시그널선 | 추세 전환 |
| **터틀 트레이딩** | 20일 최고가 돌파 | 10일 최저가 이탈 | 큰 상승장 |
| **모멘텀** | 30일 전보다 비쌀 때 | 30일 전보다 쌀 때 | 추세 |
| **스토캐스틱** | %K가 20 아래에서 %D 위로 | %K가 80 위에서 %D 아래로 | 박스권 |
| **스퀴즈 모멘텀** 🌍1위 | 좁게 뭉쳤던 가격이 풀리면서 오르는 힘이 커질 때 | 그 힘이 줄어들 때 | 급등 시작 |
| **스마트 머니 (시장 구조)** 🌍2위 | 종가가 직전 고점(스윙 하이)을 넘을 때 | 종가가 직전 저점(스윙 로우)을 깰 때 | 추세 |
| **슈퍼트렌드** 🌍5위 | 종가가 ATR×3 위쪽 선을 넘을 때 | 종가가 ATR×3 아래쪽 선을 깰 때 | 큰 추세 |
| **바이앤홀드 (기준)** | 처음에 한 번 | 안 팖 | 비교 기준 |

🌍 = 해외 최대 차트 커뮤니티 [TradingView](https://www.tradingview.com/scripts/)의 커뮤니티 스크립트 역대 인기(Top) 순위예요. 3위는 MACD라서 이미 있고, 4위 Williams Vix Fix는 언제 팔지가 없어서 빼고 5위 슈퍼트렌드를 넣었어요. 원작은 차트에 그리는 지표라서, 그 지표를 쓰는 사람들이 흔히 쓰는 읽는 법으로 사고파는 규칙을 정했어요.

<details>
<summary><b>각 전략을 쉽게 풀어보면 (눌러서 펼치기)</b></summary>

- **변동성 돌파**: 가격이 "오늘 시가 + 어제 움직인 폭의 절반"을 넘으면 "오늘은 오르는 날"로 보고 사고, 다음 날 아침 9시에 무조건 팔아요. 하루 넘게 들고 있지 않아서 큰 하락을 피하기 쉬워요. 대신 오르는 척하다 떨어지는 "가짜 돌파"가 잦은 횡보장에서는 자주 손해를 봐요. (래리 윌리엄스)
- **변동성 돌파 + 이동평균**: 변동성 돌파와 같지만, 어제 종가가 최근 5일 평균보다 높을 때(상승 추세)만 사요. 하락장에서는 쉬어서 손실을 줄이는 대신, 바닥에서 막 반등하는 구간은 놓칠 수 있어요.
- **이동평균 골든크로스**: 최근 5일 평균 가격이 20일 평균보다 높으면 "상승 추세"로 보고 들고 있다가, 아래로 내려가면 팔아요. 큰 추세를 길게 타기 좋지만, 신호가 늦게 나와서 고점 근처에서 사고 저점 근처에서 팔 때도 있어요.
- **RSI 역추세**: RSI는 최근 14일 동안 오른 힘과 내린 힘을 0~100으로 나타낸 숫자예요. 30 아래면 "너무 많이 떨어졌다"고 보고 사고, 70 위면 "너무 많이 올랐다"고 보고 팔아요. 계속 떨어지기만 하는 하락장에서는 손실이 커질 수 있어요.
- **볼린저 밴드**: 20일 평균 가격 위아래로 "평소 흔들리는 폭"만큼 띠를 그려요. 가격이 띠 아래로 떨어지면 평소보다 많이 싸진 걸로 보고 사고, 평균선 위로 돌아오면 팔아요. 박스권에 강하고, 폭락장에서는 더 떨어질 수 있어요.
- **MACD**: 12일 평균과 26일 평균의 차이(MACD)가 그 차이의 9일 평균(시그널)보다 크면 "오르는 힘이 붙는 중"으로 보고 들고 있어요. 추세 전환을 비교적 빨리 잡지만, 횡보장에서는 매매가 잦아져 수수료가 쌓여요.
- **터틀 트레이딩**: 1980년대 전설적인 "터틀" 트레이더들의 규칙이에요. 최근 20일 최고가를 넘으면 사고, 최근 10일 최저가를 깨면 팔아요. 큰 상승장을 끝까지 타는 데 강하지만, 작게 자주 잃고 가끔 크게 버는 구조라 승률은 낮은 편이에요.
- **모멘텀**: 오늘 가격이 30일 전보다 높으면 들고 있고, 낮으면 팔아요. "오르는 건 계속 오르는 경향"을 이용하는 단순한 전략이에요. 추세가 바뀌는 구간에서는 반응이 늦어요.
- **스토캐스틱**: 최근 14일 가격 범위에서 지금 가격이 어디쯤인지를 0~100으로 봐요. 20 아래(바닥권)에서 다시 올라서기 시작하면 사고, 80 위(꼭대기권)에서 꺾이면 팔아요. 강하게 오르는 장에서는 너무 일찍 팔 수 있어요.
- **스퀴즈 모멘텀** (LazyBear): 트레이딩뷰에서 역대 '좋아요'를 가장 많이 받은 지표예요. 가격이 한동안 좁은 범위에 갇혀 있으면 "힘을 모으는 중(스퀴즈)"으로 봐요. 그게 풀리면서 오르는 힘이 커지면 사고, 그 힘이 한 번이라도 줄면 팔아요. 터지는 움직임을 잘 잡지만, 빨리 팔아서 긴 상승을 다 못 먹을 때가 많아요.
- **스마트 머니 (시장 구조)** (LuxAlgo의 Smart Money Concepts): 원작에서 핵심인 "시장 구조 돌파(BOS/CHoCH)"만 따왔어요. 양옆 5일보다 높은 꼭짓점을 고점, 낮은 바닥을 저점으로 잡아요. 종가가 직전 고점을 넘으면 사고, 직전 저점을 깨면 팔아요. 위아래로 흔드는 장에서는 고점에 사서 저점에 팔기 쉬워요.
- **슈퍼트렌드** (KivancOzbilgic): 최근 10일 평균 흔들림(ATR)의 3배만큼 떨어진 곳에 선을 긋고, 가격이 오르면 선도 따라 올라와요. 종가가 그 선 아래로 떨어지면 팔고, 반대쪽 선을 넘으면 사요. 큰 추세를 끝까지 타기 좋지만 횡보장에서는 몇 번씩 속을 수 있어요.
- **바이앤홀드**: 아무 판단 없이 사서 계속 들고 있어요. 다른 전략들이 "그냥 들고 있기"보다 나은지 비교하는 기준이에요.

</details>

**백테스트 규칙**: 수수료 0.05%를 반영하고, 장중 돌파 매수는 목표가(시가가 이미 위면 시가)에 체결된 것으로 가정해요. 실제 봇과 백테스트는 같은 계획(`DayPlan`)을 같은 규칙으로 실행해요 (`mypie/strategies/base.py` 참고). 실제로는 시가보다 조금 비싸게 사고 싸게 팔 때가 많아서(미끄러짐), 자주 사고파는 전략일수록 실제 결과가 조금 낮을 수 있어요.

## 살 때·팔 때 조합과 손절선

**조합**: 줄마다 **살 때**와 **팔 때**를 따로 골라요. 한쪽에 전략을 하나 또는 둘까지 넣을 수 있어요.
- **A** — 전략 하나 (살 때·팔 때가 같은 전략 하나면 예전과 똑같이 움직여요. 기존 줄은 모두 이거예요)
- **A 그리고 B** — 둘 다 신호가 나야
- **A 또는 B** — 하나라도 신호가 나면
- 편집기에서 **＋ 하나 더**로 두 번째 전략을 넣고, 가운데 **그리고/또는**을 골라요. **✕**로 다시 하나로 돌아가요.

조합은 이렇게 판단해요 (`mypie/strategies/combo.py`):
- 전략마다 "혼자 굴렸다면 지금 들고 있을까"를 봉마다 따라가요 (그림자 계좌). RSI처럼 신호가 잠깐만 나는 전략도 "그리고"가 엇갈리지 않게요.
- **안 들고 있을 때는 살 때 쪽만**, **들고 있을 때는 팔 때 쪽만** 봐요. 사자·팔자가 동시에 켜져도 헷갈리지 않아요.
- **사는 건 새 신호일 때만**: 살 때 쪽이 '안 삼 → 삼'으로 바뀐 봉에 사요. 그래서 조합으로 바꾸면 새 매수 신호가 날 때까지 기다렸다가 사요.
- **파는 건 상태로**: 팔 때 쪽이 '안 들고 있음'이면 팔아요 ("그리고"면 둘 다, "또는"이면 하나라도).
- 과거 봉이 모자라 판단을 못 하는 전략은 '팔자'로 치지 않아요.
- 장중 돌파·이탈 가격은 조건에 맞게 합쳐요.

**손절선** (줄마다 선택, 기본은 안 씀, 1~50%): 산 값(수수료 포함 평단)보다 정한 %만큼 떨어지면 **전략과 상관없이 바로** 팔아요 (`mypie/stoploss.py`).
- 산 직후에도 지켜요. 전략의 이탈 가격이 손절선보다 위면 그쪽이 먼저예요.
- 손절로 판 뒤에는 **매수 신호가 한 번 꺼졌다가 다시 켜질 때** 다시 사요. 신호가 계속 켜져 있는 전략이 바로 다시 사서 손절이 소용없어지지 않게요. 돌파 가격 매수는 그 자체가 새 신호라 그대로 사요.
- 종목 카드에 🛑 손절선과 손절 가격이 보이고, 손절 뒤에는 "손절 뒤 쉬는 중"으로 나와요.

## 전략 시뮬레이션

웹페이지 **전략 순위 · 시뮬레이션** 카드에서 "그때 이렇게 사고팔았다면?"을 바로 계산해요 (파이에 모아 둔 봉으로, 처음 고른 조합은 몇 초).
- 고르는 것: **종목 · 판단 주기 · 과거 기간**(예: 최근 3달) · **살 때·팔 때 전략(조합)** · **손절선**
- 보여주는 것: 100만 원이 얼마가 됐을지, 그냥 들고 있었다면과의 차이, 최대 낙폭, 사고판 횟수·승률, 가격 차트 위 매수▲·매도▼와 들고 있던 구간, 내 돈 곡선
- **같은 기간 순위표**: 13개 전략을 같은 기간·같은 손절선으로 굴린 순위예요. 조합을 고르면 맨 위에 **조합** 줄이 생기고 "이 전략들 사이에 넣으면 몇 위"인지 보여줘요. 줄을 누르면 그 전략으로 바꿔 계산해요.
- 손절선을 켜면 모든 전략에 같은 손절선을 넣어서 굴려요. 비교선 "그냥 들고 있었다면"은 손절 없이 계산해요.
- **포트폴리오 설정에 넣기**를 누르면 고른 종목·주기·조합·손절선이 편집기로 넘어가요. 실제로 바뀌는 건 PIN을 넣고 **설정 적용**을 눌렀을 때예요.
- 위 가격 차트에서 종목을 고르면 시뮬레이션도 따라가요.

> 한 기간에서 1등인 조합이 다른 기간에서도 잘 되는지 꼭 확인하세요. 많이 비교해서 고를수록 과거에만 우연히 맞는 조합이 뽑히기 쉬워요.

## 실거래 안전장치

- **두 가지 한도 방식**
  - **금액 한도** (예: 10만 원): 그 금액을 비중대로 나눠서 시작하는 봇 전용 장부예요. 번 돈은 각 줄의 다음 매매에 자동으로 다시 들어가요. 봇이 직접 산 코인만 팔고, 업비트에 원래 있던 원화·코인은 그대로 둬요.
  - **계좌 전액**: 업비트 계좌의 원화와 **포트폴리오 종목 코인 전체**를 비중대로 굴려요. 원래 있던 코인은 그 종목 줄의 보유분이 돼서 매도 신호면 전부 팔아요. 살 때는 그 줄의 원화 몫 전부(계좌 기준 여유분 0.5% 제외)로 사고, **입금하면 비중대로 나눠서** 보유 중인 줄은 바로 추가 매수해요. 포트폴리오에 없는 코인은 건드리지 않아요. 수익률은 "넣은 돈 합계" 기준이라 입출금해도 틀어지지 않아요.
- **정전·재부팅·통신 끊김에도 멈추지 않음**: 설정과 장부는 DB에 남아서 전원이 들어오면 봇이 자동으로 이어서 해요. 주문마다 고유 번호를 붙여 두기 때문에, 주문 도중에 끊겼으면 다시 켜질 때 그 번호로 **업비트에 결과를 물어서 장부를 맞추고 곧바로** 전략대로 매매해요. 같은 주문이 두 번 나가지 않아요.
- **주문은 절대 그냥 다시 보내지 않음**: 결과를 모르는 주문은 먼저 확인하고, 업비트가 거절한 주문(잔고 부족 등)은 잠시 기다렸다가 다시 판단해요.
- **집 IP 변경 감지**: 10분마다 집 공인 IP를 확인해서, 업비트에 등록한 IP와 달라지면 웹페이지에 경고를 띄워요. 업비트가 IP 때문에 거절해도 빨간 경고가 떠요. 허용 IP만 고치면 자동으로 다시 주문해요.
- **API 키 만료 알림**: 업비트 키는 발급 후 1년이면 만료되고 연장이 안 돼요. 만료 **30·14·7·3·1일 전**에 텔레그램으로 알리고, **만료됐거나 쓸 수 없는 키**(업비트 `expired_access_key`·`invalid_access_key`, 토스증권 `invalid_client`)면 하루 한 번 **갱신 방법까지** 보내요. 매매 알림을 꺼도 이건 보내요. 새 키가 통하면 "다시 연결됐어요"로 알려줘요.
- **키 보관**: API 키는 파이의 `~/My_Pie/.env`에만 있어요 (권한 600, GitHub에 안 올라감). **출금 권한은 절대 주지 마세요.**
- **PIN**: 웹페이지에서 설정을 바꾸려면 PIN이 필요해요. 5번 틀리면 10분 동안 잠겨요.
- **실거래 확인**: 실거래로 바꿀 때는 "실제 돈으로 주문이 나간다"에 체크해야 해요.

Windows PC에서 코드를 고쳐 파이로 바로 올릴 때는:


## 업비트 API 키 받는 법

모의투자는 키가 필요 없어요. **실거래할 때만** 필요해요.

1. PC에서 **[업비트](https://upbit.com) 웹사이트**에 로그인 → **마이페이지 → Open API 관리**로 들어가요.
2. **권한**은 이 세 개만 체크해요.
   - ✅ 자산조회 ✅ 주문조회 ✅ 주문하기
   - ❌ **출금 관련 권한은 절대 체크하지 마세요.** 키가 털려도 돈을 빼갈 수 없게요.
3. **허용 IP(특정 IP에서만 실행)** 칸에 **집의 공인 IP**를 넣어요. 주문 권한이 있는 키는 IP 등록이 필수예요.
   - 공인 IP는 공유기 관리 화면(ipTIME이면 첫 화면의 "외부 IP")에서 확인할 수 있어요.
   - 집 IP가 바뀌면 키가 안 먹혀요. 그럴 땐 여기서 IP만 새로 바꿔 주면 돼요.
4. 약관에 동의하고 **카카오페이/네이버 등으로 본인 인증**을 하면 **Access Key**와 **Secret Key**가 나와요.
   - ⚠️ **Secret Key는 이 화면에서 한 번만 보여줘요.** 바로 다음 단계를 진행하세요. 키를 카톡이나 메일로 보내지 마세요.
   - 키는 **발급 후 1년이 지나면 만료되고 연장할 수 없어요.** 웹페이지 계좌 옆에 만료일이 보이고, 30일 전부터 경고가 떠요. 만료되면 새로 받아서 같은 방법으로 등록하면 돼요 (`python3 -m mypie.keys --check`로 만료일 확인).
5. 파이에 SSH로 접속해서 키를 등록해요. 붙여넣어도 화면에 안 보이는 게 정상이에요.
   ```bash
   cd ~/My_Pie && python3 -m mypie.keys
   ```
   "연결 성공!"과 함께 업비트 잔고가 나오면 끝이에요.

## 실거래 시작하기

1. 업비트에 **원화를 입금**해요. 투자 한도만큼 + 수수료 여유분이 필요해요. 예: 한도 10만 원이면 10만 1천 원 정도.
2. 웹페이지 **포트폴리오 설정** 카드에서 순서대로 고르세요.
   - 줄마다 종목 · 판단 주기 · 비중(%) · 살 때·팔 때 전략 · 손절선 정하기 (**＋ 종목 추가**, **⚖️ 균등 배분**). 전략 목록은 그 종목·주기 기준 순위대로 나와요. 종목 칸에는 업비트 원화 종목이 전부 나와요.
   - 비중을 **0%**로 두면 그 줄은 사지 않고 지켜보기만 해요 (들고 있던 코인은 매도 신호 때 팔고, 판 돈은 대기 원화로). 나중에 비중만 올리면 바로 그 전략대로 매매해요. 합계가 이미 100%일 때 **＋ 종목 추가**를 누르면 0%로 들어가요.
   - 계좌: **실거래**
   - 투자 한도: 예) `100000`, 또는 **업비트 계좌 전액** 체크 (위 [실거래 안전장치](#실거래-안전장치) 참고)
   - 금액 한도는 **시작 금액**이에요. 10만 원이 20만 원이 되면 다음 매매는 알아서 20만 원으로 해요. 다시 바꿀 필요 없어요. 잃으면 줄어든 금액으로 해요.
   - ⚠️ 한 줄의 몫이 **5,000원(업비트 최소 주문 금액)보다 작으면 살 수 없어요.** 금액이 적으면 종목 수를 줄이세요.
   - "실제 돈으로 주문이 나간다는 걸 이해했어요" 체크
   - PIN 입력 → **설정 적용**
3. 10초 안에 봇이 실거래로 바뀌어요. 상단 칩이 빨간 **실거래**로 바뀌고, "업비트 실제 잔고"가 보이면 정상이에요.
4. 그만하려면 계좌를 **모의투자**로 바꾸면 돼요. 보유 중인 코인은 그때 팔아요.

## 텔레그램 로그인·알림

텔레그램을 연결하면 두 가지가 돼요.
- **웹페이지 로그인**: `:8000`에 들어오면 텔레그램으로 **2자리 코드**가 `42 (192.168.0.10)`처럼 요청한 기기 IP와 함께 와요. 코드를 넣으면 열려요.
  - 로그인은 **쿠키(그 기기)로도, IP로도 최대 24시간** 기억해요. 다른 앱(텔레그램 등)의 링크로 열어도 다시 묻지 않아요. 24시간이 지나면 다시 물어요.
  - 로그아웃하면 그 기기와 IP 기억이 같이 지워져요.
  - 코드는 5분 동안만 유효하고, 3번 틀리면 지워지고, 30초에 한 번·1시간에 10번까지만 보내요. 코드를 요청하거나 로그인하면 텔레그램으로 알려줘서 누가 시도하는지 바로 알 수 있어요.
- **알림**: 매수·매도 체결(손절 포함), 오류, 집 IP 변경, 입금 감지, 설정 변경, 봇 재시작, **API 키 만료**(갱신 방법 포함)를 텔레그램으로 보내요.
- **SSH 로그인 감시**: 파이의 SSH 기록을 따라 읽어요.
  - 집 밖(공인 IP)에서 **로그인 성공**하면 바로 알려요. 집 안에서 들어온 건 조용히 둬요.
  - **로그인 실패**는 바로 알리지 않고 모아서, **낮 12시와 밤 12시**에 반나절치를 IP별 횟수·시도한 아이디로 요약해서 보내요. 실패가 없던 반나절은 보내지 않아요.
- **아침 리포트**: 거래일이 바뀌는 09시 매매가 끝나면 지난 24시간 매매 기록, 확정 손익, 종목별 상태를 보내요. 주식은 장 마감 뒤 마감 리포트를 보내요.
- **명령어**: 봇에게 보내면 답장해요 (입력창 메뉴에도 떠요).
  - `/상태` (`/status`) — 지금 포트폴리오와 총 자산
  - `/기록` (`/trades`) — 최근 매매 기록 10건
  - `/주식` (`/stock`) — 주식 금고와 종목 계좌
  - `/도움` (`/help`) — 명령어 안내

**연결하는 법 (웹페이지에서)**
1. 텔레그램 앱에서 **@BotFather**를 찾아 `/newbot`을 보내요. 봇 이름과 아이디(끝이 `bot`)를 정하면 **봇 토큰**을 줘요.
2. 웹페이지 **텔레그램** 카드에 토큰과 PIN을 넣고 **연결 시작**을 눌러요.
3. 화면에 나온 내 봇을 텔레그램에서 찾아 **아무 메시지나** 보내면 자동으로 연결돼요.

연결한 뒤에는 같은 카드에서 알림·로그인 켜고 끄기, 테스트 메시지, 연결 끊기를 할 수 있어요 (PIN 필요).
토큰과 채팅 번호는 파이의 `.env`에만 저장돼요. 로그인 코드 자릿수(2~8)와 로그인 유지 시간(`session_hours`, `trust_hours`)은 `config.toml`의 `[web]`에서 바꿔요.

**텔레그램이 안 될 때 (비상용, 파이 SSH에서)**
```bash
python3 -m mypie.telegram --code    # 로그인 코드를 화면에 출력
python3 -m mypie.telegram --off     # 연결 끊기 (로그인 없이 열림)
```

## 주식 자동매매 (토스증권)

국내 주식(코스피·코스닥)을 [토스증권 Open API](https://developers.tossinvest.com)로 사고팔아요. 웹페이지 위쪽 **📈 주식** 버튼으로 들어가요.
코인 봇과 따로 돌아서(서비스 `mypie-stock`, 기록 `data/stock.db`) 한쪽에 문제가 생겨도 다른 쪽은 계속 돌아요.

**금고 + 종목 계좌**
- 실제 계좌는 하나지만 장부로 **금고**와 **종목 계좌** 여러 개로 나눠 써요.
- **금고**: 쉬는 돈이에요. 계좌에 입금하면 금고로 들어오고, 출금하면 금고에서 빠져요.
- **종목 계좌**: 종목 하나 + 전략 하나(또는 [살 때·팔 때 조합](#살-때팔-때-조합과-손절선)) + 손절선(선택)이에요. 자기 **잔액**으로만 사고, **팔면 그 돈은 종목 계좌 잔액에 남아요** (금고로 가지 않아요).
- 종목은 **이름이나 코드로 검색**해서 골라요 (예: 삼성전자, 005930). 고르면 그 종목의 전략 순위(최근 3년)를 바로 계산해요.
- 카드의 **전략 바꾸기**에서 살 때·팔 때 전략과 손절선을 바꿔요 (PIN). 손절선만 바꾸면 전략은 그대로 이어서 판단해요.
- 금고 ↔ 종목 계좌 이체는 화면에서 직접 해요 (PIN). 이체해도 바로 사지 않고, **전략이 매수 신호를 낼 때만** 사요. 이미 주식을 들고 있으면 늘어난 잔액은 다음 매수 때까지 기다려요.
- 실거래에서는 계좌에 원래 있던 그 종목 주식도 그 종목 계좌로 가져와요 (가져온 순간의 시세가 원가). 종목 계좌가 없는 주식은 건드리지 않아요.
- 전략을 바꿔도 주식은 팔지 않고 새 전략이 판단해요. 주식이 남은 종목 계좌는 지울 수 없어요.
- 모의투자와 실거래는 금고·종목 계좌가 따로예요. 모의투자 금고는 100만 원으로 시작하고, 화면에서 가상 입금·출금을 할 수 있어요.

**언제 사고파나**
- 장이 열리는 날 **09:00** 첫 확인 때 종목 계좌마다 계획을 세우고, 매도 신호가 난 계좌를 먼저 판 다음 매수 신호가 난 계좌를 사요.
- **09:00~15:20**에는 10초마다 가격을 보면서 돌파 매수·이탈 매도를 해요. 15:20부터는 마감 동시호가라 새 주문을 내지 않아요.
- 판단은 **일봉**으로만 해요. 주말·휴장일은 쉬고, 임시 휴장일은 토스증권 장 달력으로 확인해요.
- **판단·순위·시뮬레이션은 모두 정규장(09:00~15:30) 일봉으로 해요.** 봇은 정규장에서만 사고팔기 때문이에요.
  - 토스증권 시세는 KRX와 NXT를 합친 값이에요. NXT 종목(삼성전자 등)은 2025-03-04부터 일봉이 08:00~20:00 전체로 나와요.
    예를 들어 2026-10-20 삼성전자 일봉 시가는 08:00 NXT 가격인 222,500원인데, 09:00 정규장 시가는 219,500원이었어요.
  - 그래서 NXT 종목은 그날부터의 일봉을 1분봉(09:01~15:30)으로 다시 만들어서 써요. 그 전 날짜와 NXT가 아닌 종목(ETF 등)은 원래 일봉이 정규장과 같아서 그대로 써요.
  - 처음 고른 NXT 종목은 정규장 일봉을 만드느라 몇 분 걸려요. 장중에는 매매가 늦어지지 않게 조금씩 만들어요.
  - 계획에 쓰는 '오늘 시가'도 정규장 첫 1분봉 시가이고, 카드의 등락률도 전날 정규장 종가 기준이에요.
  - 가격 차트의 분봉은 NXT 시간까지 그대로 보여줘요 (아래 화면 설명 참고).
- 주문은 '지금 가격 ±1%' 지정가로 내서 바로 체결되게 해요. 20초 안에 다 안 되면 남은 수량은 취소하고 체결된 만큼만 적어요.
- 장 마감 뒤 텔레그램으로 마감 리포트를 보내요. 매매 알림은 📈로 시작해요.

**화면**: 금고·종목 계좌 카드(괄호 안에 바이앤홀드 비교), 가격 차트(**5년(주봉)·1년·6개월·3달·1개월·1주(30분봉)·1일(5분봉)·1시간(1분봉)**), 전략 시뮬레이션(종목 검색 + 조합 + 손절선), 매매 기록·이벤트.
- 분봉 차트는 NXT(넥스트레이드) 시간까지 **08:00~20:00**을 그리고, 정규장 밖은 옅게 칠해요. 거래가 없는 시간 칸은 빼서 ETF처럼 정규장만 거래되는 종목은 09:00~15:30만 보여요.

**전략**: 코인과 같은 13가지에 **주식 전용 4가지**를 더 써요. 백테스트에는 수수료 0.015%와 팔 때 증권거래세 0.2%를 반영해요.

| 주식 전용 전략 | 사는 때 | 파는 때 |
|---|---|---|
| **52주 신고가 돌파** | 최근 250거래일(약 1년) 최고가를 장중에 넘을 때 | 종가가 20거래일 평균 아래 |
| **거래량 돌파** | 거래량이 평소의 2배 넘게 터지면서 20거래일 최고 종가를 넘을 때 | 종가가 10거래일 평균 아래 |
| **이격도 매매** | 종가가 20거래일 평균보다 8% 넘게 낮을 때 | 평균보다 2% 높아졌을 때 |
| **이동평균 정배열** | 5·20·60·120거래일 평균이 위에서부터 차례로 놓일 때 | 5거래일 평균이 20거래일 평균 아래로 |

**연결하는 법**
1. PC에서 **토스증권 웹(WTS)** → **설정 → Open API**에서 **Client ID · Client Secret**을 발급받아요.
2. 같은 화면 **허용 IP 관리**에 집 IP를 등록해요 (업비트에 등록한 IP와 같아요).
3. 토스증권 앱에서 **투자자지시 거래소**를 **통합(SOR)**으로 해 두세요. 아니면 주문이 거절돼요.
4. 파이에서 `python3 -m mypie.toss`를 실행해 두 값을 붙여넣으면 끝이에요. 1분 안에 주식 봇이 **모의투자**로 시작해요.
5. 모의투자로 지켜본 뒤, 웹페이지 주식 화면 **계좌 설정**에서 실거래로 바꿔요 (PIN + '실제 돈' 체크).

```bash
python3 -m mypie.toss --check    # 키가 되는지, 주문가능 현금 확인
```

> ⚠️ 토스증권 API에는 모의투자 서버가 없어서, 실거래로 바꾸면 첫 주문부터 진짜예요. 처음엔 종목 계좌 하나에 작은 금액만 넣어서 확인하세요.

## 라즈베리파이 상태

코인 화면 아래 **🍓 라즈베리파이** 카드에 15초마다 나와요.
- CPU 온도, CPU 사용, 메모리, 저장공간, 켜진 시간, 기록 DB 크기
- **전력 (추정)**: 파이 3B에는 전력 센서가 없어서 CPU 사용량으로 어림한 W예요 (쉴 때 약 1.4W ~ 다 쓸 때 약 3.7W). 막대 끝은 **공식 권장 어댑터 5V 2.5A(12.5W)**예요.
  - 막대 색은 전압 상태예요. W가 작아 보여도 **지금 전압이 모자라면 빨강**, 켜진 뒤 한 번이라도 모자랐으면 주황이에요.
  - 전압이 모자라면 파이가 스스로 CPU 속도를 낮춰요. 속도보다 문제는 기록을 쓰는 중에 전압이 떨어져 **SD카드가 깨질 수 있다는 것**이에요. 정격 어댑터와 짧고 굵은 케이블을 쓰세요.

## 자주 쓰는 명령

파이에서:
```bash
systemctl --user status mypie-bot mypie-web mypie-stock   # 상태
journalctl --user-unit mypie-bot -f             # 봇 로그 실시간 보기 (주식은 mypie-stock)
systemctl --user restart mypie-bot mypie-web mypie-stock  # 설정 파일을 바꾼 뒤 재시작
python3 -m mypie.bot --once                     # 한 번만 돌려서 점검 (서비스를 멈춘 뒤에)
python3 -m mypie.pin                            # PIN 바꾸기
python3 -m mypie.keys                           # 업비트 키 등록/변경
python3 -m mypie.keys --check                   # 업비트 키가 되는지와 만료일 확인
python3 -m mypie.toss                           # 토스증권 키 등록/변경 (--check로 확인)
python3 -m mypie.telegram --code                # 텔레그램이 안 될 때 로그인 코드 받기
python3 -m unittest discover -s tests -v        # 테스트 (실제 주문·텔레그램 없음)
```

모의투자를 처음부터 다시 시작하려면 봇을 멈추고 `data/mypie.db`를 지운 다음 다시 시작해요. PIN도 다시 만들어야 해요.

## 설정 파일

`config.toml`은 처음 설치할 때 `config.example.toml`에서 복사돼요. 종목, 계좌, 한도, 전략은 웹페이지에서 바꾸는 게 편하고, 이 파일은 처음 시작할 때의 기본값과 세부 숫자(전략 파라미터, 순위 기준 등)를 정해요. 항목 설명은 [config.example.toml](config.example.toml)에 있어요.
